# BanoQabil-DeliciousBites

This repository contains a full restaurant website project — my Mini Project 1 
from the Web Development course (Bano Qabil). The website is built using HTML 
and CSS. It has a Home page with a food menu, an Order page with a complete 
online order form, and a Contact page for customer queries.

## Task
The assignment required building a 3-page HTML-only restaurant website 
(Home, Order, Contact) using specific HTML tags, attributes, and input 
types as per the given instructions. The **HTML structure strictly follows 
the assignment requirements**, while the **CSS design/styling was done 
based on my own creative choices**.

## Pages
- **index.html** – Restaurant intro, food menu table, specials list, YouTube video, audio, Google Map
- **order.html** – Online order form using all major input types (text, email, tel, password, radio, checkbox, number, range, date, time, color, file, select, textarea, submit, reset)
- **contact.html** – Contact form, restaurant details, map, social links, video

## Bonus Features Implemented
- Internal linking (`href="#menu"`) to jump to sections on the same page
- `<video>` tag showing kitchen prep

## Technologies Used
- HTML5
- CSS3
- Font Awesome (icons)
